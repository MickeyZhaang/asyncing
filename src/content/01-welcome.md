# Welcome to Asyncing

This is a small, local-first place for writing a textbook. Every file in `src/content` becomes a chapter automatically.

## Writing chapters

Create a new `.md` file, add a title and an order, then refresh the app. There is no CMS, database, or server involved.

> The source files are the book.

## What the renderer understands

- Headings and paragraphs
- **Bold**, _emphasis_, and `inline code`
- Ordered and unordered lists
- Blockquotes and fenced code blocks
- [Links](https://example.com)

```ts
const chapter = "Write in Markdown";
```
